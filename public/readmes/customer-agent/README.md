# customer-agent

Ingests your knowledge base, answers common questions, creates tickets for complex issues, and escalates to humans when confidence is low.

## How it works

- Receives your task via natural language prompt
- Uses its specialized tools and models to complete the task
- Returns a structured result

## Parameters

| Field | Description |
|---|---|
| **Input** | Natural language prompt describing your task |
| **Output** | Structured output relevant to the agent's domain |

## Example prompts

- Ask customer-agent to help with a support task.
