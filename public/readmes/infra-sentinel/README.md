# infra-sentinel

Connects to AWS/GCP/Azure, watches metrics and logs, correlates anomalies across services, and can auto-scale or rollback with approval.

## How it works

- Receives your task via natural language prompt
- Uses its specialized tools and models to complete the task
- Returns a structured result

## Parameters

| Field | Description |
|---|---|
| **Input** | Natural language prompt describing your task |
| **Output** | Structured output relevant to the agent's domain |

## Example prompts

- Ask infra-sentinel to help with a devops task.
