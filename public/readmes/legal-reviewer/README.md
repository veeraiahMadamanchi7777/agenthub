# legal-reviewer

Parses contracts, flags non-standard clauses, compares against your playbook, and suggests redline edits.

## How it works

- Receives your task via natural language prompt
- Uses its specialized tools and models to complete the task
- Returns a structured result

## Parameters

| Field | Description |
|---|---|
| **Input** | Natural language prompt describing your task |
| **Output** | Structured output relevant to the agent's domain |

## Example prompts

- Ask legal-reviewer to help with a legal task.
